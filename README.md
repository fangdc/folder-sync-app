# FolderSync

把 Mac 上的一个文件夹**单向同步**到移动硬盘或另一个目录。

选好源文件夹和目标文件夹，App 会在目标下自动创建一个同名文件夹，把内容同步进去；
目标文件夹里的其他东西不会被碰。

**[下载最新版本](https://github.com/fangdc/folder-sync-app/releases/latest)** · macOS 14 或更高 · Intel / Apple 芯片通用

---

## 功能

| 能力 | 说明 |
| --- | --- |
| 自动建同名子文件夹 | 选「源文件夹」+「目标文件夹」，实际写入 `目标文件夹/源文件夹名/` |
| 两种同步模式 | **增量同步**（默认，只补新增和修改）/ **镜像同步**（目标与源严格一致，源里删掉的目标也删） |
| 手动同步 | 点「立即同步」，或菜单栏图标里的「立即同步全部」 |
| 定时同步 | 按间隔（5 / 15 / 30 分钟、1 / 3 / 12 小时）或每天固定时刻 |
| 预览改动 | 同步前先看清楚会复制什么、会删什么，只读不写 |
| 多任务 | 同时管理多组「源 → 目标」配对，互不影响 |
| 登录时自动启动 | 常驻菜单栏，关掉窗口也在后台按频率同步 |
| 自动忽略系统文件 | `.DS_Store`、`.Spotlight-V100`、`.fseventsd` 等不会同步 |
| 只传变化的部分 | 用「大小 + 修改时间」判断，时间戳容差 2.5 秒，兼容 exFAT/FAT32 |
| 同步记录 | 每次运行的时间、结果、数据量、失败原因都留档，并逐条列出新建 / 修改 / 删除了哪些文件；明细不截断（保留最近 300 次运行） |

### 安全设计

- **目标文件夹必须已经存在**才会执行，只自动创建它下面的同名子文件夹；
  移动硬盘没挂载时，不会在本机磁盘上凭空造目录再写入。
- **递归保护**：目标在源内部、源在目标内部、两者相同，都会拒绝执行。
- **镜像删除有兜底**：源里一个文件都没扫到时会跳过删除并警告，防止误清空目标。
- **删除优先进废纸篓**，外接盘不支持时才真正删除。
- 复制采用「先写临时文件 → 原子替换」，中途失败或断电不会留下半个文件。
- **中断保护**：连续 8 次写入失败会判定磁盘已断开并停止。

## 系统要求

- macOS 14 或更高，Intel 和 Apple 芯片都可以。
- 无需安装其他组件。目标位置可以是移动硬盘、U 盘、另一个内置磁盘或网络卷。

## 安装

1. 从 [Releases](https://github.com/fangdc/folder-sync-app/releases/latest) 下载 `FolderSync-1.1.0.dmg`，打开后把 **FolderSync.app** 拖到左边的「应用程序」文件夹。

2. 这个 App 没有 Apple 开发者证书签名，第一次打开会被 macOS 拦一下。
   先做下面任意一种放行操作（只需一次）：

   **方式一（终端）**：按 ⌘空格 输入 `Terminal` 回车，然后执行：

   ```sh
   xattr -dr com.apple.quarantine /Applications/FolderSync.app
   ```

   如果提示 `Operation not permitted`，在命令最前面加 `sudo` 和一个空格，再输一次密码。

   **方式二（不用终端）**：双击打开一次 → 提示「无法打开」→ 点「完成」，
   然后到「系统设置 → 隐私与安全性」，滚到「安全性」，点「仍要打开」，再确认一次。

3. 首次运行 macOS 会询问是否允许访问「桌面 / 文稿 / 下载 / 可移动宗卷」，选「允许」。

> 用 U 盘或局域网把 DMG 拷给别人时，普通文件拷贝不带隔离标记，对方不用做第 2 步。

## 第一次同步

1. 打开 App，点左上角「**新建同步任务**」（首次打开会直接显示欢迎页，可在里面创建）。
2. **源文件夹**：电脑上要同步出去的文件夹，点「选择文件夹」选取。
3. **目标文件夹**：移动硬盘的根目录（或任意目标目录），同样点「选择文件夹」。
   这一行会显示最终写入的完整路径，形如 `/Volumes/移动硬盘/桌面`。
4. 点「**预览改动**」看一眼会复制什么，再点「**立即同步**」。

如果源文件夹属于其他 App 的容器目录（例如某些聊天软件的聊天记录），
需要到「系统设置 → 隐私与安全性 → 完全磁盘访问权限」里手动把 FolderSync 加进去。

## 两种同步模式

详情页「方式」里切换：

- **增量同步（默认，推荐）**：只同步新增和修改的内容；源里删掉的文件，目标里仍然保留。
- **镜像同步**：新增、修改、删除都同步，目标与源严格一致。**用之前建议先「预览改动」**。

镜像模式删掉的文件，在支持的系统磁盘上会先进「废纸篓」，还能找回；
移动硬盘常见的 exFAT 格式不支持废纸篓，会直接删除。

## 自动同步

详情页「频率」里可选：

- **仅手动**：只有点按钮时才同步。
- **按间隔**：5 / 15 / 30 分钟，或 1 / 3 / 12 小时。
- **每天定时**：在时间框里选具体时刻，可直接输入，也能用步进器调整。

打开「设置」里的「登录时自动启动」后，App 会常驻菜单栏，关掉主窗口也不退出，
继续按各任务的频率同步；同步期间菜单栏图标会转动。

## 多个任务

- 每个任务是一个「源文件夹 → 目标文件夹」的配对，互不影响。
- 任务名固定取源文件夹的名字，不能自定义，免得电脑上和硬盘上的名字对不上。
- 删除任务会先确认；只删任务和它的记录，已经同步出去的文件不会被动。

## 同步记录

每次同步完成后，详情页的「最近记录」会显示这次运行的时间、结果和数据量；
点「查看全部记录」可以打开完整的同步历史。

- 有文件变更的记录，第二行右侧会出现「**同步详情**」，展开后逐个列出这次**新建、修改、删除了哪些文件**，以及文件大小。
- 删除文件夹时，会连里面的子文件夹和文件一起列出；`.DS_Store` 等系统垃圾文件不显示。
- 文件夹改名会被识别成一次「**修改**」，里面的文件不会重复算作新增；空文件夹改名也会显示「修改 1」。
- 明细不截断，保留最近 300 次运行；列表超过 180pt 高时在框内滚动。

## 它对你的电脑做了什么

- 对**源文件夹只读**，不修改、不移动、不删除里面的任何文件。
- 只在「目标文件夹 / 源文件夹同名子文件夹」里写文件，目标里的其他内容不碰。
- 复制时保留修改时间和权限；不联网、不上传、没有统计上报。
- 数据放在：

  ```
  ~/Library/Application Support/FolderSync/
  ├── config.json     任务配置
  └── history.json    同步记录（最近 300 次运行，含逐条文件明细）
  ```

- 如果开了「登录时自动启动」，会写一个开机自启项：
  `~/Library/LaunchAgents/local.foldersync.autostart.plist`
- **彻底卸载**：先关掉「登录时自动启动」，删掉 `/Applications/FolderSync.app`，
  再删掉 `~/Library/Application Support/FolderSync/` 即可。

## 已知限制

- 只做单向同步（源 → 目标），不做双向合并，也不处理冲突。
- 用「大小 + 修改时间」判断变化，不做内容哈希；同大小、同时间但内容不同的极端情况会漏过。
- 不跟随目录符号链接（符号链接本身会被复制过去），避免循环引用。
- 不特殊处理 `Photos Library.photoslibrary` 这类「包」，会当作普通目录逐文件复制；
  要整块拷贝请用访达。
- App 是本地 ad-hoc 签名、没有公证，所以别的 Mac 上首次打开需要按「安装」里的方式放行。
- 菜单栏图标很多时，macOS 会把新图标折叠到 `«` 里；按住 `⌘` 拖动可以调整顺序。
- 移动硬盘每次休眠唤醒后，macOS 可能重新询问外接盘授权（表现为每次定时同步都弹窗）。
  把 FolderSync 加进「系统设置 → 隐私与安全性 → 完全磁盘访问权限」可彻底不再询问。
- 「预览改动」最多列出前 300 项，实际同步不受这个显示上限影响。
- 单次同步的明细全部保存；首次全量同步很大的目录时，`history.json` 会明显变大。
- 同步失败的原因记在「同步记录」里；更细的运行时错误可在「控制台.app」里搜 `FolderSync` 查看。
